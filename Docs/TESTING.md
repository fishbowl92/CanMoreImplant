## 공개 전 수동 확인 — 아직 미완료

1. Harmony와 이 모드만 활성화한 새 시험 저장에서 시작 시 빨간 오류가 없는지 확인.
2. 건강 → 개요/수술/임플란트를 반복 전환. 탭 겹침·클릭 영역·원래 수술 기능 확인.
3. 한국어/영어, 작은 해상도 및 화면 배율 변경 후 긴 이름 줄바꿈 확인.
4. 아무 부품도 없는 대상: 후보가 회색이며 재고 0개여도 표시되는지 확인.
5. 왼쪽 팔에 생체공학 팔 장착: 왼쪽 의수 숨김, 초월공학 팔 표시, 오른쪽 의수 유지.
6. 하위 후보 표시를 켜면 왼쪽 의수가 복원되는지 확인.
7. 눈/다리의 상위 교체, 특수 전투·작업 부품의 보존 확인.
8. 부위 상실/부품 제거/수술 성공 뒤 목록이 약 1초 안에 갱신되는지 확인.
9. 포로·동물·종족 모드·시체·유아에서 오류 없이 표시하고 제한을 설명하는지 확인.
10. 재료 부족/연구 제한/수술 조건 제한의 설명 확인.
11. 대표 의체 추가 모드, 모듈형 의체 모드와 하나씩 조합해 확인.
12. 저장 후 재실행, 모드 제거 후 저장 사본 로드 확인.
13. 자연 부위가 건강하면 낮은 효율 교체품이 숨겨지고, 손상·결손이면 필요한 교체품이 다시 표시되는지 확인.
14. 구울과 일반 정착민을 번갈아 선택: 구울 전용 부품이 일반인 목록에 없고 구울 목록에 있는지 확인.
15. 메카니터와 비메카니터 비교: 대역폭·통제 임플란트가 전용 대상에게만 나오는지 확인. 메카링크 자체는 예외. 수술 정의가 없는 아이템 사용형 후보는 원래 탐색 범위 밖임.
16. 같은 모드의 효율 105%/110% 팔 및 바닐라 125%/150% 팔을 번갈아 장착해 README의 표와 대조.
17. 반복 출처 제목이 없고 긴 임플란트명/효과명이 좁은 창에서도 세 열 안에서 줄바꿈되는지 확인. 열 제목은 스크롤과 무관하게 유지되어야 함.
18. 하위 후보 표시를 켜도 구울/메카니터 대상 제한이 풀리지 않는지 확인.
19. 손상된 팔의 왼쪽 현재 효율과 오른쪽 교체품 기본 효율이 구분되는지 확인.
20. 통증 감소, 갑옷 피부 방어력, 메카니터 대역폭의 부호/단위를 원래 정보 카드와 대조.
21. 여러 효과는 외 N개를 표시하고 마우스 설명에 요약 목록이 나오는지 확인. 조건부/특수 효과는 잘못된 고정값을 표시하지 않아야 함.
